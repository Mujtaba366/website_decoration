HOW IT WORKS
================================================================================

LOGIN FLOW:
┌─────────────────────────────────────────────────────┐
│ User visits /admin                                  │
└────────┬────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────┐
│ Already logged in? → Redirect to /admin/dashboard   │
│ Not logged in? → Show login form                    │
└────────┬────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────┐
│ User enters username & password                     │
│ authenticateAdmin() queries Supabase admin_users    │
│ Credentials match? → Create session in localStorage │
└────────┬────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────┐
│ Redirect to /admin/dashboard                        │
│ Show admin interface with top nav                   │
└─────────────────────────────────────────────────────┘

PROTECTED PAGES:
┌─────────────────────────────────────────────────────┐
│ AdminProtectedLayout checks getAdminSession()       │
├─────────────────────────────────────────────────────┤
│ Session valid & not expired?                        │
│  ✓ YES → Show page with AdminTopNav                │
│  ✗ NO → Redirect to /admin (login)                 │
└─────────────────────────────────────────────────────┘

================================================================================
TROUBLESHOOTING
================================================================================

Q: Can't login?
A: • Check admin_users table exists in Supabase
   • Verify environment variables are set
   • Check credentials match exactly (case-sensitive)

Q: Getting redirected to login constantly?
A: • Session may have expired (24-hour timeout)
   • Clear localStorage: dev tools → Application → localStorage → delete
   • Check browser allows localStorage

Q: Admin pages show loading state forever?
A: • Check Supabase connection
   • Verify environment variables
   • Check browser console for errors

Q: Can't find admin pages?
A: • Type URL directly: http://localhost:3000/admin
   • Admin pages NOT linked from main site (by design)

Q: TypeScript errors?
A: • Run: npm run typecheck
   • Check all imports are correct
   • Verify node_modules are installed
