AZIZA DECORATION RENTAL & WEDDING SHOP - QUICK SETUP
================================================================================

STEP 1: CREATE VIRTUAL ENVIRONMENT
================================================================================
Open PowerShell in the project root folder, then:

cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
cd ..

(This will take 2-3 minutes)


STEP 2: CREATE .env FILE
================================================================================
In the backend/ folder, create a file named ".env" with this content:

DEBUG=True
DJANGO_SECRET_KEY=django-insecure-dev-key-change-in-production
ALLOWED_HOSTS=localhost,127.0.0.1
CORS_ALLOWED_ORIGINS=http://localhost:5173,http://localhost:3000
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
ENVIRONMENT=development


STEP 3: GET SUPABASE CREDENTIALS (FREE)
================================================================================
1. Go to https://supabase.com
2. Click "Start your project"
3. Sign up with email
4. Create a new project (free tier)
5. Wait 1-2 minutes for it to initialize
6. Go to Settings (bottom left icon)
7. Click "API"
8. Copy these values into your .env file above:
   - Project URL → SUPABASE_URL
   - Anon public key → SUPABASE_KEY
   - Service role secret → SUPABASE_SERVICE_ROLE_KEY


STEP 4: CREATE DATABASE TABLES
================================================================================
1. In Supabase, click "SQL Editor" (left sidebar)
2. Click "New Query"
3. Open the file "SUPABASE_SCHEMA.md" in this folder
4. Copy ALL the SQL code from that file
5. Paste it into Supabase SQL Editor
6. Click "Run" button
7. Tables are created!


STEP 5: ADD SAMPLE DATA
================================================================================
Still in Supabase SQL Editor, run this SQL:

-- Rental products
INSERT INTO products (name, slug, description, type, category, base_price, images) VALUES
('White Flower Arch', 'white-flower-arch', 'Beautiful white flower arch for ceremonies', 'rental', 'Arches', 250, '["arch.jpg"]'::jsonb),
('Round Gold Backdrop', 'round-gold-backdrop', 'Elegant 8ft gold round backdrop', 'rental', 'Backdrops', 350, '["backdrop.jpg"]'::jsonb);

-- Shop products
INSERT INTO products (name, slug, description, type, category, base_price, images) VALUES
('Personalized Champagne Flutes', 'personalized-flutes', 'Set of 2 engraved champagne glasses', 'sale', 'Glassware', 45, '["flutes.jpg"]'::jsonb),
('Monogrammed Napkins', 'monogrammed-napkins', 'Set of 50 personalized paper napkins', 'sale', 'Table Settings', 25, '["napkins.jpg"]'::jsonb);

-- Add availability for rental items
WITH dates AS (
  SELECT generate_series(current_date, current_date + interval '90 days', interval '1 day')::date as date
)
INSERT INTO rental_availability (product_id, date, is_available)
SELECT (SELECT id FROM products WHERE slug = 'white-flower-arch'), date, true
FROM dates;


STEP 6: START BACKEND
================================================================================
Open PowerShell in project root:

cd backend
.\venv\Scripts\Activate.ps1
python manage.py runserver

You should see:
  Starting development server at http://127.0.0.1:8000/
  Quit the server with CONTROL-C.

✅ Backend is running!


STEP 7: START FRONTEND
================================================================================
Open a NEW PowerShell window in project root (leave backend running):

cd frontend
npm install
npm run dev

You should see:
  VITE v5.x.x  ready in xxxx ms
  ➜  Local:   http://localhost:5173/
  ➜  press h to show help

✅ Frontend is running!


STEP 8: TEST IT
================================================================================
1. Open http://localhost:5173 in your browser
2. Click "Explore Rentals" - should see White Flower Arch and Backdrop
3. Click "Browse Shop" - should see Champagne Flutes and Napkins
4. Click on any product to see details
5. Try the booking/checkout flow!

✅ Everything works!

TROUBLESHOOTING
================================================================================

Q: Virtual environment won't activate
A: Make sure you're in the backend/ folder:
   cd backend
   python -m venv venv
   .\venv\Scripts\Activate.ps1

Q: Backend won't start - Module errors
A: Make sure venv is activated and requirements installed:
   .\venv\Scripts\Activate.ps1
   pip install -r requirements.txt

Q: Frontend won't start
A: Install dependencies:
   cd frontend
   npm install
   npm run dev

Q: "Cannot connect to Supabase"
A: Check your .env file has correct credentials
   Verify Supabase project is active
   Make sure database tables exist

Q: Products not showing in frontend
A: 1. Check tables exist in Supabase
   2. Make sure you inserted sample data
   3. Check backend is running (http://localhost:8000/api/products/)
